## 範囲と安全性

- GPSは長距離の案内に使用します。
- BLE RSSIは近さと傾向を示しますが、物理的な方向は測れません。
- 実験的なBLEスイープは90秒後または15 m移動後に失効します。
- Android RangingはAndroid 16以降で、端末に応じてChannel Sounding、
  Wi-Fi NAN RTT、BLE RSSIを使用します。
- 音響ソナーはBeepBeep方式に似た3回の双方向測定で短距離を推定します。

ソナーは1〜25 mで障害物がない場合に最も有効です。耳の近くで使用しないで
ください。子どもや動物には高周波音が聞こえる場合があります。測定結果は
救助隊の判断に代わるものではありません。

## レイアウト検証

1. 狭い画面でレーダーを開きます。
2. 金属に近づけてコンパスの校正状態を悪化させます。
3. 警告が1つだけ表示され、円が移動しないことを確認します。
4. 金属から離れ、端末を8の字に動かし、画面がずれずに警告が消えることを
   確認します。
5. スイープを開始し、ガイドが円の上に重なることを確認します。
6. 90秒待つか15 m以上移動し、再測定が要求されることを確認します。

## Android Ranging

Android 16以降の端末2台と`RANGING`権限が必要です。

1. 対象端末でメッシュとレーダー同意を有効にします。
2. もう一方でレーダーを開き、無線測定を開始します。
3. 測定距離と誤差範囲が表示されることを確認します。
4. 1、3、5、10 mで、見通しありと壁越しの両方を試します。

## Android–iPhone音響ソナー

1. 両方でアプリを開いたままにし、レーダーとマイクを許可します。
2. Bluetoothヘッドセットを切断し、スピーカーとマイクを塞がないでください。
3. 1〜3 m離して音響測定を開始します。
4. 3回の測定中は静止し、巻尺と比較します。
5. 5、10、20 mおよび騒音環境でも繰り返します。

各回で2つのchirpを検出できない場合、HearthBitは結果を破棄する必要が
あります。

## Android常駐通知

メッシュを有効にし、Android 14以降で通知をスワイプして消します。メッシュ
動作中は通知が再表示され、メッシュ停止後は再表示されないことを確認します。
